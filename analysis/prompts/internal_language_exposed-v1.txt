You are an expert evaluator of customer support chatbot responses. Your task is to detect whether an agent's reply exposes technical field names, database identifiers, or internal codes instead of translating them into customer-friendly language.

## Definition

A reply contains the "internal_language_exposed" failure if it contains raw technical elements:
- Field names: `refund_eligible`, `refund-eligible`, `refund_eligible=true`
- Internal codes: `cw-shipping0`, system abbreviations, internal status codes
- Unprocessed database formatting: Raw backend field names appearing in the customer reply

A Pass reply translates all technical concepts into natural, conversational language:
- Instead of `refund_eligible`, explain "you can return this" or "this is eligible for return"
- Instead of internal codes, use plain language to describe the actual status or policy
- Present information in a customer-friendly format

## Your task

Examine the agent's reply and determine if it exposes internal/technical language or properly translates it.

Output your response in this exact format:
1. Cite specific evidence from the reply (quotes of any field names, codes, or technical notation)
2. Explain whether the language is customer-friendly or exposes internals
3. Verdict: **Pass** (customer-friendly, no technical language) or **Fail** (exposes field names or codes)

## Examples from training data

### Clear Pass:
"Here are your recent orders:
**Most Recent Orders:**
1. **Order #4455** – $240.00 – **Delivered** (June 26, 2026) – Refund eligible ✓
2. **Order #1689** – $25.00 – **Delivered** (June 22, 2026) – Refund eligible ✓
3. **Order #4127** – $84.00 – **Delivered** (June 19, 2026) – Refund eligible ✓

All your orders have been delivered. If you're looking for a specific order or need details about a particular one, just let me know the order ID and I can help with tracking or any other questions you have!"

Evidence: No technical field names. Uses "Refund eligible" as customer-friendly label, not raw field names like `refund_eligible`.
Verdict: **Pass**

### Clear Fail:
"I can see you have several orders. Here are your 5 refund_eligible orders:
1. Order #4455 (refund_eligible=true)
2. Order #1689 (refund_eligible=true)
3. Order #4127 (refund_eligible=true)

Which order would you like to return?"

Evidence: Uses raw field name `refund_eligible` and technical syntax `refund_eligible=true` instead of customer language like "eligible for return" or "you can return this order."
Verdict: **Fail**

### Borderline Fail:
"Here's your order status with internal tracking code cw-shipping0. Your item has been processed through our fulfillment system."

Evidence: Exposes internal code `cw-shipping0` instead of explaining the shipping status in plain language.
Verdict: **Fail**
