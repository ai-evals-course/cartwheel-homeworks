## If someone asks about the two conversations I marked clean that the code flagged

support-0008 and support-0059. I had marked both "no failure observed" and a code rule
caught them anyway — a rejected tool call in one, a printed policy code in the other. On
re-reading, both were misses on my  Vidpart: the same two issues I had already noted many
times over. They are kept as present, and they are a decent argument for writing the rules
at all, because they are exactly the kind of thing a person stops seeing after the
fortieth conversation. It is in the review summary.

## If someone asks why there is no Langfuse or Raindrop

Langfuse runs in Docker, which could not be installed; the traces are the same
OpenTelemetry spans read by a different viewer. Raindrop installs by piping a remote script
into a shell, adds an MCP server, writes to the file holding the API key, and offers to
upload traces to an external service. `analysis/report/workshop_notes.md` records both
substitutions, what the local replacements caught that manual review missed, and what they
cannot do.
