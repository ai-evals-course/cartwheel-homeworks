## If someone asks why not gpt-4o-mini

The endpoint serves three models and none of them is OpenAI's. I checked before building
anything. I used a different Muse model from the one the agent runs on, deliberately — a
judge sharing the model it grades is least likely to spot that model's own mistakes.
`analysis/report/workshop_notes.md` records all four substitutions.

## If someone asks about the test disagreement you didn't fix

One of the four test false alarms looks like another label error of mine — the same
restocking pattern. I left it. Correcting a test label after seeing the prediction fits the
model to the held-out set and destroys the measurement. The judge is probably better than
sixty percent, and I can't claim it without fresh labels.
